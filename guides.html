Contributor Guides

Everything you need to know to start contributing to open-source projects.

1. What is Open Source?

Open-source software is code that is designed to be publicly accessible—anyone can see, modify, and distribute the code as they see fit. Contributing to it helps you gain real-world coding experience and collaborate with global developers.

2. Why Contribute?

  • Build a strong portfolio and GitHub contribution graph.
  • Learn standard industry workflows like Git, code reviews, and issue tracking.
  • Network with mentors and developers from around the world.

3. Essential Git Basics

Before contributing, make sure you know these core commands:

  • git init: Initializes a new local Git repository.
  • git clone : Copies a remote repository to your local machine.
  • git add .: Stages your modified files for a commit.
  • git commit -m "message": Saves your staged changes with a description.
  • git push origin : Uploads your commits to GitHub.
  • git pull: Fetches and merges changes from the remote repo.
  • git checkout -b : Creates and switches to a new working branch.
